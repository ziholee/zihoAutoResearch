# 실제 학습·평가 루프 예제

이 예제는 **개발 소스 전용**입니다. 공개 v0.3.0에는 필요한 `research` 명령이 없습니다. Python 표준 라이브러리로 합성 회귀 모델을 실제로 학습하고, 로컬 모의 LLM을 통해 기준 실험 → 후보 계획 → 승인 → 실행 → 비교 → 중단·재개를 연결합니다. 클라우드 API, 실제 Codex 추론, API 키나 추가 ML 패키지는 필요하지 않습니다.

## 실행하기

현재 개발 소스를 내려받고 저장소 루트에서 실행합니다. 예제는 wheel에 포함되지 않으므로 소스의 `examples/` 폴더가 필요합니다. Python 3.11 이상을 사용하세요.

```sh
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell에서는 위 줄 대신:
# .venv\Scripts\Activate.ps1
python -m pip install .
python examples/ml-loop.py --output ./demo-ml
```

`demo-ml`은 존재하지 않는 새 경로여야 합니다. 이 명령은 예제 프로젝트를 만들고 기준·후보 실험을 실행한 뒤, 안전한 지점에서 모의 서버를 종료하고 별도 프로세스로 재개까지 확인합니다. 예제 안에서는 고정된 학습 프로그램과 모의 응답에 대한 전송 동의·승인을 자동으로 입력합니다. 실제 프로젝트에서는 내용을 검토한 뒤 승인해야 합니다.

직접 두 번으로 나누어 실행할 수도 있습니다.

```sh
python examples/ml-loop.py --output ./demo-ml-paused --pause
python examples/ml-loop.py --output ./demo-ml-paused --resume
```

첫 명령은 후보 실행 결과를 기록한 뒤 해석·판단 전에 종료합니다. 두 번째 명령은 같은 프로젝트를 읽어 남은 해석·판단을 수행하며 학습을 다시 실행하지 않습니다. 재개 시 저장된 로컬 포트가 다른 프로세스에 점유되어 있으면 안전하게 실패합니다. 해당 프로세스를 확인하고 포트가 비워진 뒤 다시 시도하세요.

## 무엇을 학습하고 비교하나요?

- **데이터:** 서로 다른 난수 시드로 학습 데이터 96개(seed 42)와 평가 데이터 64개(seed 2026)를 생성합니다. 실제 사용자 데이터나 외부 데이터 다운로드는 없습니다.
- **기준:** 학습 데이터의 타깃 평균으로 적합한 상수 예측 모델입니다.
- **후보:** 같은 학습 데이터에서 최소제곱법으로 적합한 선형 회귀 모델입니다.
- **평가:** 두 모델을 같은 평가 데이터와 변경하지 않은 평가기로 평가하여 평균제곱오차(MSE)를 계산합니다. 낮을수록 좋습니다. 평가 데이터로 계수를 적합하지 않습니다.

후보 세션은 선택된 기준 실험을 연결하여 `research start --mode candidate`로 생성합니다. 대화형 전용 `research next`를 호출하는 예제는 아닙니다.

모의 LLM은 정해진 후보 변경안을 반환합니다. 실제 수치는 학습·평가 프로그램이 계산하며 LLM이 생성한 점수를 관측값으로 쓰지 않습니다. 실험 기록과 평가 결과가 일치하는지, 기준과 후보가 비교 가능한 조건을 공유하는지, 재개 후 실행 횟수가 그대로인지 확인합니다.

출력 폴더의 `summary.json`과 터미널 요약에서 `baseline_score`, `candidate_score`, `improvement`로 평가값과 차이를 확인하고, `execution_count: 2`, `state: complete`, `resumed_without_execution: true`로 두 번의 학습과 재개 완료를 확인합니다. 중단 시에는 요약의 `state`가 `paused_after_observation`이고 후보 연구 세션의 실제 상태는 `observed`입니다. `metrics`에는 연구 호출 측정값이 포함됩니다. 모의 서버의 토큰 사용량은 미확인으로 남으며 실제 모델의 토큰·비용·응답 속도를 나타내지 않습니다.

## 검증 범위와 한계

이 예제는 고정 점수를 기록하는 기존 [학습 없는 예제](../examples/mock-cycle.py)보다 한 단계 더 나아가 실제 적합·평가 결과와 CLI 기록의 연결을 확인합니다. 중단은 결과가 저장된 **안전한 경계**에서 수행합니다. 실행 중 강제 종료, 불명 실행의 복구와 중복 방지 전체를 이 예제 하나로 검증했다고 주장하지 않습니다. 해당 절차는 [API 연구 세션 사용법](research-api.md)의 복구 안내와 회귀 검사를 따릅니다.

후보와 데이터는 예제를 위해 미리 정했습니다. 점수 향상이 실제 LLM의 연구 능력이나 새로운 데이터에서의 일반화 성능을 증명하지 않습니다. 실제 API·Codex 호환성 검증, 수동 에이전트+Git 대비 완료 시간·사용자 개입·기록 누락·재개 오류 비교는 남아 있습니다. 다음 범위는 [설계 문서](llm-experiment-cli.md)를 확인하세요.
