# zihoAutoResearch

**LLM이 ML 파이프라인을 생성·실행·평가·수정하는 그래프 기반 연구 루프를 통해, 주어진 자원 안에서 더 나은 전체 파이프라인을 찾아내는 도구.**

외부 ML 프로젝트의 코드와 데이터를 받아 LLM이 연구 맥락을 이해하고, 데이터 처리·피처·모델·학습 전략을 실행 가능한 코드로 구성합니다. 실험 결과를 해석해 다음 가설을 만들고, 전체 파이프라인을 반복적으로 개선하는 것을 목표로 합니다.

## 핵심 흐름

프로젝트·데이터·목표·자원 예산 입력 → 프로젝트 이해 → 파이프라인 생성 → 실행 → 평가 → 원인 분석 → 파이프라인 수정

- **LLM:** 가설 수립, 전략 선택, 코드 생성·수정, 결과 해석 및 다음 실험 설계
- **그래프:** 실행 순서, 조건부 분기, 재시도, 이전 단계 복귀, 종료 제어
- **검증 시스템:** 고정된 평가 규칙, 자원 제한, 재현성 및 실험 채택 조건 검사
- **실험 기억:** 성공과 실패의 근거를 기록하고 후속 연구에 활용

## 목표 산출물

- 예산 안에서 찾은 검증된 최선의 파이프라인 코드와 설정
- 학습된 모델과 평가 결과
- 재현 가능한 실행 정보와 선택 근거를 담은 실험 이력

## 현재 상태

제품 방향을 정리한 설계 준비 단계입니다. 실행 가능한 연구 루프는 아직 구현되지 않았습니다. 특정 ML 문제에 제품 범위를 고정하지 않으며, 초기 지원 환경과 프레임워크는 상세 설계에서 결정합니다.

모든 프로젝트의 자동 수용이나 전역 최적값을 보장하지 않습니다. 정해진 평가 기준과 자원 예산 안에서 검증된 개선을 축적하는 것이 목표입니다.
